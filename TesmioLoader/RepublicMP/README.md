# RepublicMP (Two States & Co-op Multiplayer Plugin)

Co-op multiplayer plugin for *Workers & Resources: Soviet Republic* (**One State** & **Two States on One Map** modes), built for [TesmioLoader](https://github.com/MaxLegend/TesmioLoader).

See the root [README.md](../../README.md) for full documentation, features, installation instructions (RU / EN), and build steps.
