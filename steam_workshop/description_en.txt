[h2]🚀 Installation & Launch Rules:[/h2]
[b]Important:[/b] Both players must run the same game version and [b]RepublicMP v1.3.1[/b].

[b]Method 1 — Via Steam Workshop (Recommended):[/b]
1. Subscribe to this mod on Steam Workshop (both players).
2. Open the Workshop mod folder: [i]Steam\steamapps\workshop\content\784150\3823543010\[/i] and run [b]START-COOP.bat[/b] [b]once[/b] (it automatically copies the [i]dinput8.dll[/i] proxy loader and menu icons into your [i]SovietRepublic\[/i] game directory next to [i]SOVIET64.exe[/i]).
3. [b]Done![/b] From now on, simply launch the game normally via the [b]"Play"[/b] button in Steam (select the standard 64-bit version). All future Workshop updates will load automatically!

[b]Method 2 — Friend Pack Archive (RepublicMP_Friend_Pack.zip / Manual Install):[/b]
1. Extract the archive into your [i]SovietRepublic\[/i] game folder (where [i]SOVIET64.exe[/i] is located) or run [b]START-COOP.bat[/b] from the extracted folder.
2. Launch the game via Steam or [i]SOVIET64.exe[/i].

[b]How to Start a Co-op Session:[/b]
• [b]HOST:[/b] In the main menu, click [b]"CO-OP" -> "Host Server"[/b]. Optionally adjust [b]"Co-op Settings"[/b] ([i]1 or 2 States[/i], [i]Treasury 100% / 50-50[/i], [i]Border Zone[/i], [i]Map Borders[/i], [i]Mod Sync Mode[/i]), then select [b]"Continue Co-op"[/b], [b]"Co-op Saves"[/b], [b]"Import Singleplayer"[/b], or [b]"New Custom Game"[/b].
• [b]CLIENT (Player 2):[/b] Wait until the Host loads the map (and enters the Co-op Waiting Lobby), open [b]"CO-OP" -> "Join Server"[/b], and click [b]"Host: <Friend's Name>"[/b] in the online Steam friends list (or paste their IP / [i]steam:<SteamID64>[/i]).
