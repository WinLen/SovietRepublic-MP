[h1]RepublicMP — Кооперативный мультиплеер для Workers & Resources: Soviet Republic[/h1]

Полноценный кооперативный мод с пошаговой детерминированной синхронизацией ([b]Lockstep[/b]), поддержкой подключения через [b]Steam P2P[/b] (без Radmin/Hamachi и проброса портов) и двумя режимами игры!

[h2]Основные возможности:[/h2]
[list]
[*] [b]Два режима кооператива:[/b]
  1. [b]Одно государство[/b] — классический кооп с общим бюджетом и общим управлением всей республикой.
  2. [b]Два государства на одной карте (Западная ССР и Восточная ССР)[/b] — раздельные бюджеты (рубли и доллары), собственная территория каждого игрока (`X < 0` и `X >= 0`), общая пограничная зона для стыковки дорог/ЖД/ЛЭП/труб и переводы средств между государствами.
[*] [b]Расширение карты:[/b] снятие 2-км пограничного ограничения застройки (400 км²) + генератор гигантских карт [b]30x30 км (900 км²)[/b] прямо из меню.
[*] [b]Подключение через Steam P2P в 1 клик:[/b] список друзей онлайн прямо в игре, подключение без белого IP и VPN.
[*] [b]Комфортная совместная игра:[/b] 3D-маркер курсора напарника и быстрый телепорт к нему (`T`), пинги на карте (`Alt + ЛКМ`), внутриигровой чат (`Enter`), общая скорость симуляции.
[*] [b]Автообновление:[/b] мод автоматически проверяет и скачивает свежие версии с GitHub Releases при запуске `START-COOP.bat` или прямо из меню (`INSERT`).
[/list]

[h2]Как запустить после подписки в Steam Workshop:[/h2]
1. Откройте папку мода (в Steam: ПКМ по игре -> Свойства -> Установленные файлы -> Обзор, затем поднимитесь в `steamapps\workshop\content\784150\`) или скачайте архив с GitHub Releases.
2. Запустите [b]START-COOP.bat[/b] (он сам найдёт `SOVIET64.exe`, проверит обновления и запустит игру с модом). Для удобства можно один раз запустить [b]CREATE-DESKTOP-SHORTCUT.bat[/b], чтобы создать ярлык на Рабочем столе.
3. В игре нажмите клавишу [b]INSERT[/b], чтобы открыть меню кооператива RepublicMP!
